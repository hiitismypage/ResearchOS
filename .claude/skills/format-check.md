### БЛОК 1 — Авторские имена в тексте

**Проблема:** В российском академическом письме не принято называть авторов явно в теле текста. Вместо этого ставится только номер источника в квадратных скобках.

**Паттерны-нарушители** (ищи с помощью grep или чтения):
- `[Фамилия] [глагол] \[N\]` — «Иванов \[5\] показал, что...»
- `в работе [Фамилия]` — «в работе Петрова и Сидорова»
- `[Инициалы]. [Фамилия]` в теле абзаца (не в библиографии)
- `[Ф.И.О.]` с инициалами — «А.А. Цыплаков \[21\]»

**Как исправить:**
- «Иванов \[5\] показал, что X» → «Было показано, что X \[5\]»
- «Жодар и Мерелло доказали, что...» → «Доказано существование...\[14\]»
- «в работе А.А. Цыплакова \[21\]» → «в \[21\]»
- «А.А. Цыплаков строит модель...» → «В \[21\] построена модель...»

**Допустимо оставить:**
- Именные концепции: «матрица Мура--Пенроуза», «аппарат Леонтьева», «модель Кейнс--Шумпетер» — это названия понятий, не авторские ссылки
- Исторические факты об основателях метода без явной цитатной функции

### БЛОК 2 — Маркированные списки

**Проблема:** Markdown `- item` Pandoc конвертирует в маркированный список Word. По ГОСТ нужны тире.

**Автоматическое исправление Python-скриптом:**

```python
import re

for filepath in chapter_files:
    with open(filepath, encoding='utf-8') as f:
        content = f.read()
    # Заменяем markdown-маркер на en-dash ГОСТ
    content = re.sub(r'^- ', '– ', content, flags=re.MULTILINE)
    with open(filepath, 'w', encoding='utf-8') as f:
        f.write(content)
```

**После замены проверь пунктуацию пунктов по правилу ГОСТ 2.105-95:**
- Пункты с **заглавной буквы** (самостоятельные предложения) → каждый заканчивается `.`
- Пункты с **строчной буквы** (продолжают вводную фразу после `:`) → каждый заканчивается `;`, последний — `.`

**Пример правильно:**
```
Методология включает:
– аппарат динамического межотраслевого баланса в дискретном времени;
– агентное моделирование с ограниченной рациональностью агентов \[18\];
– методы матричного анализа.

Структура модели:
– Добывающая промышленность, $N_1 = 32$. Поставляет первичные ресурсы.
– Электроэнергетика, $N_2 = 27$. Формирует универсальный промежуточный ресурс.
```

### БЛОК 3 — Нумерация формул

**Правило:** каждая формула нумеруется в пределах главы — (N.M), где N — номер главы, M — порядковый номер в главе. Нумерация начинается с (N.1) и идёт без пропусков.

**Шаг 3.1 — Найди все формулы в главе N:**

Сканируй все строки вида `$$...$$ ` и `$...$` — ищи формулы без номера.

Запусти диагностику:
```python
import re

with open(filepath, encoding='utf-8') as f:
    content = f.read()

# Найти все номера формул в файле
nums = sorted(set(
    int(re.match(r'\d+', x).group())
    for x in re.findall(rf'#?\({chapter}\.(\d+)', content)
))
print(f'Гл.{chapter}: формулы {nums}')

# Проверить пропуски
if nums:
    for expected in range(1, max(nums)+1):
        if expected not in nums:
            print(f'  ⚠ Пропуск: ({chapter}.{expected})')
```

**Шаг 3.2 — Убери blockquote-префиксы у формул:**

Строки вида `> $$...$$` — это артефакты конвертации из DOCX. Исправь:
```python
# Убрать "> " перед $$
content = re.sub(r'^> (\$\$)', r'\1', content, flags=re.MULTILINE)
# Убрать > \begin{array} конструкции
content = re.sub(
    r'\$\$\\begin\{array\}\{r\}\n([^\n]+)\n\\end\{array\}\$\$',
    lambda m: f'$${m.group(1).strip()}$$',
    content
)
```

**Шаг 3.3 — Добавь номера пропущенным формулам:**

Для каждой формулы `$$...$$` без номера:
1. Определи, к какому разделу относится
2. Присвой следующий номер в последовательности
3. Вставь номер внутрь блока: `$$формула\quad\quad\quad\quad\quad\quad\quad\quad(N.M)$$`

Формат числа внутри math-среды: `\quad\quad...(N.M)` — количество `\quad` подбирай так, чтобы номер уходил вправо (примерно 8–12 `\quad` для коротких формул).

**Шаг 3.4 — Проверь согласованность нумерации:**

После нумерации убедись что:
- Нет одного номера у двух разных формул
- Все номера в тексте-ссылках (типа «из уравнения (N.M)») указывают на существующие формулы

### БЛОК 4 — Рисунки

**Правило ГОСТ:** ссылка в тексте → изображение → подпись под изображением.

**Шаг 4.1 — Проверь нумерацию:**

Рисунки нумеруются в пределах главы: Рисунок 2.1, Рисунок 5.3 и т.д. Проверь что:
```python
caps = re.findall(r'^Рисунок (\d+)\.(\d+)', content, re.MULTILINE)
# Должны идти 2.1, 2.2, 2.3 без пропусков
```

Если рисунки пронумерованы глобально (Рисунок 1, Рисунок 2...) — перенумеруй по-главно.

**Шаг 4.2 — Проверь структуру каждого рисунка:**

Для каждого `![](...)` в тексте убедись что:
1. **Перед изображением** есть текст со ссылкой «...показан(ы) на рисунке N.M» или «(см. рисунок N.M)»
2. **После изображения** сразу идёт строка подписи: `Рисунок N.M -- Название рисунка`

Правильный блок:
```markdown
На рисунке 5.1 представлены нормированные траектории выпуска.

![](../results/simulation/fig_1_trajectories.png)

Рисунок 5.1 -- Нормированные траектории выпуска по секторам, 2015--2045 гг.

Анализ показывает: ВВП вырастает...
```

**Шаг 4.3 — Если рисунки описаны, но не вставлены:**

Когда глава содержит текст «Рисунок N.M показывает...» без `![](...)` — это значит изображения не вставлены. Спроси у пользователя пути к файлам рисунков. После получения путей:
1. Вставь `![](путь/к/файлу.png)` перед описанием
2. Добавь подпись `Рисунок N.M -- Название`
3. Переформулируй начало описания: «Рисунок 5.1 показывает...» → «На рисунке 5.1 показано...»

**Формат подписи — только:**
```
Рисунок N.M -- Название рисунка
```
Без точки в конце, двойное тире `--`.

### БЛОК 5 — Таблицы

**Правило ГОСТ:** подпись над таблицей, выравнивание по левому краю.

**Шаг 5.1 — Проверь каждую таблицу:**

Для каждого `Таблица N.M` убедись:
1. Строка подписи идёт **перед** таблицей (не после)
2. Формат: `Таблица N.M -- Название таблицы`
3. В тексте **до** таблицы есть ссылка: «...приведены в таблице N.M» или «(см. таблицу N.M)»

**Шаг 5.2 — Проверь нумерацию:**

Таблицы нумеруются в пределах главы: Таблица 5.1, Таблица 5.2 и т.д.

```python
tables = re.findall(r'^Таблица (\d+)\.(\d+)', content, re.MULTILINE)
# Проверь последовательность и отсутствие пропусков
```

**Требования к оформлению (контролируются в DOCX, не в markdown):**
- Все границы таблицы видимы
- Шапка жирным шрифтом
- Цвет текста и фона — чёрный/белый, никаких заливок
- Размер шрифта в таблице: допустимо 12pt

### БЛОК 6 — Ссылки на источники

**Проверь по каждому источнику из `sources/bibliography.md`:**
- Хотя бы одна ссылка `\[N\]` в теле работы

Запусти сводный поиск:
```python
import re

# Загрузи все главы
all_text = ""
for filepath in chapter_files:
    with open(filepath, encoding='utf-8') as f:
        all_text += f.read()

# Найди все упомянутые номера источников
cited = set(re.findall(r'\[(\d+)(?:;\s*\d+)*\]', all_text))
cited_nums = set()
for c in cited:
    cited_nums.update(int(x) for x in re.findall(r'\d+', c))

# Сравни с полным списком (предположи N источников)
all_sources = set(range(1, total_sources + 1))
uncited = all_sources - cited_nums
if uncited:
    print(f'⚠ Не процитированы источники: {sorted(uncited)}')
```

## Алгоритм работы скилла

```
1. Прочитай FORMAT.md и CONTEXT.md проекта
2. Составь список chapter_files = все .md в chapters/ кроме библиографии
3. Определи число глав и их номера (из заголовков # N ...)
4. Для каждой главы:
   a. Запусти диагностику (БЛОКИ 1-6) — собери список нарушений
5. Покажи сводный отчёт (см. формат ниже)
6. Спроси: «Применить автоматические правки?»
7. При подтверждении — примени исправления БЛОКОВ 2, 3 (шаги 3.2-3.3), частично 4
8. Для БЛОКОВ 1, 4.3 — выведи список мест требующих ручного решения
9. После правок — финальная проверка: повтори диагностику, покажи что осталось
```

## Правила работы

- Не трогай содержание текста — только форматирование
- Если нарушение неоднозначное (например, авторское имя в историческом контексте) — выноси на ревью, не правь автоматически
- Исправления делай через Python-скрипты или точечные Edit-вызовы — не переписывай большие куски вручную
- После каждого блока правок сохраняй файл и проверяй что нарушение устранено
- Если глава большая (>500 строк) — обрабатывай по разделам, не читай целиком сразу
- Не добавляй в файлы комментарии о том, что было исправлено — правки говорят сами за себя
