Подпроект: `projects/predpr_math_modeling/`

**Тип:** отчёт по преддипломной практике, МГТУ Бауманка, ~20 страниц.

**Согласованная структура (вариант 3 — практикоориентированный):**
- Введение — шаблон вуза (`chapters/00_введение.docx`)
- Глава 1 — Постановка задачи и теоретическое обоснование (~3 стр): МОБ, ABM, архитектура
- Глава 2 — Математическая модель пятисекторной экономики (~5-6 стр): 22 уравнения
- Глава 3 — Программная реализация, калибровка и результаты (~7-8 стр): главная
- Заключение, список литературы
- Приложение А — calibrate.cpp, Приложение Б — simulate.cpp

**Особенности:**
- Язык реализации в приложениях: C++ (Eigen), НЕ Python
- C++ файлы: `scripts/calibrate.cpp`, `scripts/simulate.cpp`, `scripts/CMakeLists.txt`
- Стиль и форматирование: идентичны `projects/diploma_math_modeling/`
- Страна калибровки не называется явно (как в дипломе)
