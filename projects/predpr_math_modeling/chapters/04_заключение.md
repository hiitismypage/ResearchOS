# Заключение

Цели преддипломной практики, сформулированные во введении, — ознакомление с реальным производственным процессом и подготовка материалов для выпускной квалификационной работы — достигнуты в полном объёме. В процессе практики выполнены все поставленные задачи: проведён обзор теоретических источников по математическому моделированию экономических систем, реализована вычислительная часть выпускной квалификационной работы, написан программный код на C++.

По существу выполненных работ получены следующие результаты.

**1. Построена математическая модель пятисекторной экономики.** Для пяти агрегированных отраслей — добывающая промышленность, электроэнергетика, обрабатывающая промышленность, строительство, сельское хозяйство — сформулирована квазистатическая форма динамического межотраслевого баланса. Вырожденность матрицы капиталоёмкости $B$ (ранг 1 при размерности $5 \times 5$) преодолена псевдообратной Мура–Пенроуза, вычисляемой через сингулярное разложение.

**2. Разработан микроуровень из 159 гетерогенных агентов.** Каждый агент описывается вектором состояния из пяти компонент (капитал, технологический уровень, ожидаемый спрос, рыночная доля, прибыль) и действует по правилам ограниченной рациональности: адаптивные ожидания, двухканальный инвестиционный бюджет, вероятностные инновационные шоки. Рыночные доли фирм эволюционируют эндогенно через конкурентный отбор.

**3. Модель откалибрована по статистическим данным.** Матрица прямых затрат $A_0$ и вектор выпуска $X_0 = 2\,141$ млрд евро получены из симметричной таблицы «затраты–выпуск» Eurostat (naio_10_cp1700, базовый год 2015). Матрица $B_0$ построена через распределение GFCF с применением абсолютного значения прироста выпуска в знаменателе. Семь поведенческих параметров откалиброваны из временных рядов 2010–2019 годов. Условие продуктивности подтверждено: $\rho(A_0) = 0{,}4441 < 1$.

**4. Реализован программный комплекс на C++ с использованием Eigen 3.4.** Два независимых исполняемых модуля — `calibrate` и `simulate` — покрывают полный вычислительный цикл: от считывания CSV-данных до записи траекторий симуляции. Трёхэтапная итерационная схема (макро → микро → агрегирование) обеспечивает замкнутую обратную связь между уровнями на каждом из $T = 30$ шагов. Листинги модулей приведены в приложениях А и Б.

**5. Проведена форвардная симуляция и верификация результатов.** Совокупный ВВП вырос с 2,141 до 4,342 трлн евро при среднегодовом темпе $\approx 2{,}4\%$. Зафиксированы три эндогенных инвестиционных пульса с периодичностью около 10–11 лет. Спектральный радиус матрицы прямых затрат монотонно снизился с 0,4442 до 0,4289 — условие продуктивности выполняется на всём горизонте. Семь из восьми верификационных проверок пройдены; единственное ожидаемое нарушение — статический баланс — объясняется инвестиционным блоком динамической постановки.

Практическая значимость выполненной работы состоит в том, что разработанный комплекс формирует самодостаточный вычислительный инструмент: однажды откалиброванный набор параметров полностью определяет характер тридцатилетней динамики без дополнительных экзогенных допущений. Программный комплекс допускает повторную калибровку по данным любой экономики с доступными IO-таблицами Eurostat, а модульная архитектура позволяет расширять число секторов и агентов без изменения общей схемы итераций.

Дальнейшее развитие модели может быть направлено на введение эндогенного ценообразования, учёт внешнеэкономических связей через блок импорта и экспорта, а также на верификацию траекторий по историческим IO-таблицам нескольких периодов.
