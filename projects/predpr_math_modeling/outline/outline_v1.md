## Структура

```
Титульный лист
Содержание

Введение                                                    ~1-2 стр (шаблон вуза: 00_введение.docx)
  Цели практики:
    - ознакомление с реальным производственным процессом
    - подготовка материалов для ВКР
  Задачи практики:
    - участие в производственном процессе
    - обзор источников для ВКР
    - выполнение вычислительной части ВКР
    - написание программного кода на С++

1 Постановка задачи и теоретическое обоснование            ~3 стр
  1.1 Динамический межотраслевой баланс Леонтьева
      - Статическая форма: X = AX + Y, матрица полных затрат (I-A)^-1
      - Динамическая форма с матрицей капиталоёмкости B
      - Псевдообратная Мура–Пенроуза B^+ при вырожденной B
  1.2 Агентно-ориентированное моделирование в экономике
      - Свойства агентов: идентифицируемость, автономность, гетерогенность
      - Ограниченная рациональность (Simon)
      - Эмерджентность макроуровня из микрорешений
  1.3 Архитектура двухуровневой гибридной модели
      - Макроуровень: МОБ с эндогенными A(t), B(t)
      - Микроуровень: 159 гетерогенных фирм
      - Схема замкнутого итерационного цикла

2 Математическая модель пятисекторной экономики             ~5-6 стр
  2.1 Состав отраслей и структура агентов
      - J={1..5}: добыча, энергетика, обработка, строительство, с/х
      - N=(32,27,41,25,34), итого 159 агентов; уравнения (2.1)-(2.3)
  2.2 Макроуровень: целевой выпуск
      - Квазистатическая система (I-A-G_U·B)x*=u; уравнение (2.4)
      - Обновление конечного спроса u(t+1)=u(t)(1+G_U); уравнение (2.5)
  2.3 Микроуровень: производственные правила фирм
      - Вектор состояния (k, θ, d^e, ω, π); уравнение (2.6)
      - LogN распределение капитала, U[θ_lo,θ_hi] для технологий
      - Адаптивные ожидания, мощность, выпуск min{}, прибыль; уравнения (2.7)-(2.15)
  2.4 Инвестиционное поведение и обновление капитала
      - Инвестиционный бюджет: κ·max{π,0}+η·max{gap,0}; уравнение (2.16)
      - Распределение по поставщикам γ_ijf; обновление k и θ; уравнения (2.17)-(2.20)
  2.5 Агрегирование: переход от микро к макро
      - Обновление A(t+1) и B(t+1) с |Δx| в знаменателе; уравнения (2.21)-(2.22)
      - Условие продуктивности ρ(A)<1; балансовая невязка; уравнения (2.23)-(2.25)

3 Программная реализация, калибровка и результаты           ~7-8 стр
  3.1 Источники данных и методика калибровки
      - Eurostat naio_10_cp1700, базовый год 2015, период 2010-2019
      - Агрегирование CPA→5 секторов (Таблица 3.1)
      - X0 по секторам (Таблица 3.2): итого 2 140 593 млн евро
      - A0: ρ(A0)=0,4441; B0: ранг 1, SVD-псевдообратная
      - u0: клипирование для добычи (высокая импортоёмкость)
      - Поведенческие параметры δ,ν,κ,η,α,p_inn,μ (Таблица 3.3)
  3.2 Архитектура программного комплекса
      - Два модуля C++17: calibrate.cpp + simulate.cpp, Eigen 3.4
      - CMakeLists.txt: find_package(Eigen3 3.4 REQUIRED NO_MODULE)
      - calibrate: 7 этапов; simulate: 3-этапный цикл (макро→микро→агрег.)
  3.3 Результаты форвардной симуляции (T=30 шагов)
      - ВВП: 2,141→4,342 трлн евро, r≈2,4%/год
      - Иерархия роста: обработка +118%, добыча +93%, стройка +61%, с/х +30%, энерг. +15%
      - 3 инвестиционных пульса ~2024/2035/2044 (эндогенный механизм клипинга B)
      - ρ(A): 0,4442→0,4289; HHI ∈ [0,032; 0,080]
  3.4 Верификация балансовой согласованности
      - 8 проверок: 7 пройдено, 1 ожидаемо нарушено (статический баланс)
      - Динамическая невязка 6-20%, без систематического роста

Заключение                                                  ~1 стр
  - Достижение целей практики (ссылка на введение)
  - Итоги по 5 задачам: модель, агенты, калибровка, C++, симуляция
  - Практическая значимость и перспективы

Список использованной литературы                            ~1 стр (8 источников)

Приложение А — Листинг calibrate.cpp
Приложение Б — Листинг simulate.cpp
```
